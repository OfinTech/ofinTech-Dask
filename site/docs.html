الوثائق

كل ما هو تقني في هذه الصفحة: التثبيت على خادم، واختيار النموذج، وربط نظامك المحاسبي، والأدوار والموافقات، والنسخ الاحتياطي، والواجهات التي تستخدمها الأنظمة الأخرى.

التثبيت على خادم تطبيق سطح المكتب النماذج والمزوّدون إدخال البيانات الأدوار والموافقات الأمن وحدود البيانات النسخ الاحتياطي واجهات الأنظمة الأخرى الحدود والفجوات المعروفة

التثبيت على خادم

حاوية للمحرّك وأخرى للوكيل العكسي الذي يستصدر شهادة TLS ويجدّدها تلقائياً. خادم افتراضي متواضع يكفي: نواتان و4 غيغابايت ذاكرة و40 غيغابايت قرص لفريق مالي من عشرة أشخاص.

المتطلبات: Docker Engine 24 أو أحدث مع Compose v2، وسجل DNS يشير إلى الخادم، والمنفذان 80 و443 مفتوحان. 

git clone https://github.com/OfinTech/ofinTech-Dask.git
cd ofinTech-Dask/server
cp .env.example .env            # set DESK_DOMAIN and DESK_PUBLIC_URL
python -m desk_engine keygen > master.key    # keep this outside the backups
docker compose up -d --build
docker compose logs -f engine   # wait for: Uvicorn running on http://0.0.0.0:8700

أول حساب تنشئه يصبح المالك. وكل حساب بعده يحتاج دعوة.

التحديث

خذ نسخة احتياطية أولاً؛ ترحيلات قاعدة البيانات تُنفَّذ تلقائياً عند التشغيل ولا يُعاد كتابتها بعد إصدارها. 

./backup.sh
git fetch origin && git reset --hard origin/main
docker compose up -d --build engine

docker compose restart وحده لا يكفي: فهو لا يعيد بناء الصورة ولا يقرأ .env من جديد.

تطبيق سطح المكتب

لمسؤول مالي واحد على جهاز واحد. لا حسابات ولا تسجيل دخول: حساب نظام التشغيل هو الشخص. وكل شيء — قاعدة البيانات والمستندات والملفات المُنتَجة — يبقى في مجلد المستخدم عندك.

إصدارات macOS وWindows وLinux في صفحة الإصدارات. وهي غير موقّعة رقمياً بعد، فيحتاج التشغيل الأول تأكيداً: على macOS افتح قائمة السياق واختر فتح، وعلى Windows اختر مزيد من المعلومات ثم تشغيل على أي حال.

النماذج والمزوّدون

المنتج غير مرتبط بمزوّد نموذج واحد. يضيف المسؤول مزوّداً لكل مساحة عمل؛ وأي خدمة بواجهة متوافقة مع OpenAI تعمل، بما فيها نموذج يعمل داخل شبكتك أنت.

  • مزوّد مستضاف: ألصق المفتاح؛ يُخزَّن مشفّراً ولا يُكتب في أي سجلّ.
  • نموذج على شبكتك: أعطِ عنوانه. وفي الوضع المختوم هذا هو النوع الوحيد المسموح.
  • التضمينات للبحث الدلالي اختيارية وتُضبط على حدة؛ وبدونها يبقى البحث بالكلمات المفتاحية ولا يحتاج أي مزوّد.

إدخال البيانات

ثلاث طرق، ويمكن الجمع بينها:

  • ملفات. Excel أو CSV لدفتر الأستاذ أو ميزان المراجعة أو الموازنة أو أي جدول. تُقرأ الأعمدة وتؤكّد أنت معنى كل عمود.
  • نظام محاسبي. اربطه مرة ويتحدّث كل ليلة. ولا يُكتب فيه شيء أبداً دون موافقة.
  • مستندات. عقود وسياسات ومحاضر مجلس وخطابات مراجعة وكشوف بنكية بصيغة PDF. والممسوحات والصور تُقرأ بالتعرّف الضوئي بالعربية والإنجليزية والإسبانية والفرنسية.

الأدوار والموافقات

أربعة أدوار، تُفحص في الخادم عند كل طلب ولا تُفحص في المتصفح أبداً: المُطّلع يقرأ، والمحرّر يغيّر سجلات مساحة العمل، والمسؤول يدير الاتصالات والأعضاء، والمالك يملك مساحة العمل.

أي إجراء يغيّر شيئاً خارج المحادثة يتوقّف وينتظر. ويرى الموافِق الأداة والمعاملات والمبالغ بالضبط. والموافقة تنتهي صلاحيتها، ومرتبطة بتلك المعاملات تحديداً، وتُستهلك مرة واحدة: فإن تغيّرت المعاملات بعد منحها، تُرفض.

الأمن وحدود البيانات

  • الأسرار المخزَّنة مشفّرة بـ AES-256-GCM بمفتاح رئيسي لا يدخل قاعدة البيانات أبداً.
  • الملفات تُشفَّر قبل كتابتها، محلياً أو في التخزين الكائني، فلا يستطيع مشغّل التخزين قراءتها.
  • معرّفات البنوك تُقنَّع قبل وصول أي رقم إلى نموذج أو سجلّ: يحتفظ الآيبان ببلده وآخر أربعة محارف.
  • الوضع المختوم يوقف كل اتصال خارجي عند نقطة إنشائه، بما في ذلك التشغيلات الجارية بالفعل.
  • سجلّ التدقيق يسجّل مَن سأل وما اعتُمد وما نُفِّذ وما عاد، ولا يستطيع التطبيق تعديل أي مُدخل أو حذفه.
  • المدفوعات لا يمكن أن توجد: أي أداة تحرّك أموالاً أو تغيّر مستفيداً تُرفض عند التسجيل وعند الاستدعاء معاً.

يحتوي المستودع على المراجعة الأمنية الكاملة ونموذج التهديد وسجلّ المخاطر المقبولة في docs/audit. اقرأها قبل أي نشر في جهة خاضعة للرقابة.

النسخ الاحتياطي

النسخ الاحتياطية مختومة بمفتاح نسخ منفصل عن المفتاح الرئيسي، لتبقى الأشياء الثلاثة متفرّقة: ملفات النسخ، والمفتاح الذي يقرأها، والمفتاح الذي يفكّ تشفير بيانات الاعتماد. 

python -m desk_engine keygen > backup.key    # once; chmod 600; keep it off the server
./backup.sh                                  # encrypted copy + checksum
python -m desk_engine backup-check <file> --key-file backup.key   # restore rehearsal

تمرّن على الاستعادة على جهاز آخر بشكل دوري. فالنسخة التي لم تستعدها مرة ليست نسخة احتياطية.

واجهات الأنظمة الأخرى

  • واجهة REST لكل ما يفعله التطبيق نفسه، تحت /api/w/{workspace}/…، وبنفس فحوص الأدوار.
  • MCP: يمكن استخدام مساحة العمل كمصدر أدوات لعميل خارجي بمفتاح وصول محدود، للقراءة فقط افتراضياً.
  • بوابة مساعد مُضمَّن تتحدّث بروتوكول AG-UI، لتشغيل مساعد مالي للقراءة فقط داخل شاشات تطبيق شريك.
  • Webhooks صادرة لكل حدث مُدقَّق، ليحتفظ سجلّ خارجي أو نظام SIEM بنسخته.

أدلّة المطوّرين ووصف OpenAPI في المستودع تحت docs/.
