## 5. Findings about the pipeline itself

1. **Dependabot alert 147** — `minimatch` (affected `< 11.0.1`, moderate) in the desktop's *development* tree
   (electron-builder → `@electron/asar`, `dir-compare`, `glob`, `filelist`). Not shipped in the app; outside the
   `--omit=dev` gate. Dependabot's own update jobs (runs 41273482815, 41274037195, 41274498358) fail because the
   fixed line (11.x) cannot be reached by a transitive bump. Status: OPEN (OP-7); fix is an `overrides` entry
   or an electron-builder release that moves to minimatch 11, then the `lockfiles` workflow. Not fixable from
   the audit machine (no npm access).
2. **Scanner images by tag** — `aquasec/trivy:latest`, `ghcr.io/gitleaks/gitleaks:v8.24.3`, `actions/*@v7`,
   `softprops/action-gh-release@v3`: by tag, not digest (AR-7).
3. **Engine test stall** — two runs before `c06346c` sat in the engine tests; the cause (a spinning wait in test
   support code) was found with the faulthandler abort now in the workflow and fixed in `4068d0d`; runs since
   complete in ~40 s. The 20-minute abort stays in place (OP-8 closes after ten clean runs).
4. **No concurrency guard** — two pushes in quick succession run two full pipelines; harmless, costs minutes.
