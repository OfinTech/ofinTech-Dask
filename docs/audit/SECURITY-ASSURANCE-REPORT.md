# Security assurance and financial integrity validation report

OfinTech Desk 1.1.0 → `main` at commit `34fac0e` (+ this commit), 1 November 2026. This report records the
**evidence** behind every security change of the audit: that the original attack is blocked, that legitimate use
still works, and that financial results and stored data are unchanged. Counts and results below are from runs
in the audit environment and from the repository's CI; nothing is claimed that was not run.

Statuses: OPEN · IN PROGRESS · SECURITY VERIFIED (attack blocked) · FUNCTIONALLY VERIFIED (legitimate path
tested) · REGRESSION VERIFIED (existing behaviour preserved) · CLOSED (all applicable verifications passed).

## 3. Adversarial testing performed

`tests/test_adversarial.py` (13 tests) tried to defeat the controls: 17 address notations and local names;
names resolving to private or dual addresses (DNS mocked); a redirect from a public host to a private one; 11
save-time URL edge cases incl. userinfo, `javascript:`, empty host; tampered, truncated, upper-cased, revoked,
idle-expired and query-string tokens; forged `Origin`/`Referer` (`null`, `%2e`, punycode, port-suffixed
look-alike, mismatched pair); a viewer attempting six privileged operations and a second use of an invitation;
eight traversal-shaped storage keys; a download name with `../`, quotes and a header break; two turns started on
one thread without yielding; an import that fails half-way (table and row both absent afterwards, connection
reusable); credential leakage through webhook payloads. Two attempts succeeded on the first run (invisible
characters before `=`; unlisted credential key names) and are closed with the suite.

Not attempted here (no live services): real DNS rebinding timing, Caddy's handling of chunked bodies, Electron
IPC from a hostile frame.

## 4. Financial integrity results

- Golden fixture from the pre-audit engine: **identical** (section 1).
- Oracles: 12/12. The one convention worth recording: the loan schedule's **total paid = principal + total
  interest**, with the last payment absorbing the rounding (12 cents on the 48-month example) — standard bank
  practice, unchanged by the audit.
- Fiscal-year grouping: the workspace fixture starts its year in April; January–March 2026 sums into the earlier
  fiscal year and the fiscal-year sums add up to the grand total — verified from the CSV rows.
- Sign conventions: revenue above budget "favourable", cost above budget "unfavourable"; no percentage against a
  zero budget — verified.
- Exports: numbers survive the CSV round trip unchanged; only text with a formula prefix gains an apostrophe;
  engine totals remain live formulas in XLSX.

## 5. Performance impact

Suite runtime 20 s → 21 s with 65 more tests. The connection-time guard adds one DNS lookup per host per 60 s in
server mode and nothing on the desktop. Dataset work moved off the loop: 200,000-row import commits in 2.7 s,
grouped queries in 13–110 ms, `/health` under 1 ms after the import (document 10). No other change is on a hot
path.

## 6. Unverified components and limitations

- **Electron (OB-12):** the sender checks compile (CI typecheck) but no automated test drives IPC from a frame;
  the desktop smoke test in CI confirms the app still shows the page with the token. A manual check on each
  OS is recommended before a release.
- **Live systems:** OAuth providers, Google sign-in, SMTP, MinIO/S3, Odoo, PipesHub, OCR with non-English data
  and the packaged installers were not exercised against real endpoints (`docs/TESTING.md`); every test mocks
  them. The guard's resolution path was tested with mocked DNS, not a real resolver.
- **Trivy:** green on `main`, but the scanner image is `latest` until a maintainer pins the tag.
- **Lockfiles:** none for `ui/` and `desktop/`; CI installs floating transitive versions.
- **One unexplained hang:** a single full-suite run stalled after a test raised inside its loop; four later
  runs completed identically. Recorded, not reproduced.

## 8. Production deployment risks (what to do before go-live)

1. Run `python -m desk_engine storage-encrypt` once on any installation that stored files before encryption was
   on (or set `DESK_STORAGE_ALLOW_PLAINTEXT=true` until it is run).
2. Add internal model, embedding or PipesHub hosts to `DESK_EGRESS_ALLOW` on a Team Server, or run sealed.
3. Set `DESK_SMTP_SECURITY` to `starttls`, `ssl` or `none` (the latter only for a login-less relay).
4. Generate lockfiles and switch CI to `npm ci`; pin the Trivy image tag.
5. Encrypt backups; keep the master key apart.
6. Decide OB-08; until then, editors' agent runs can import Google files into the workspace without approval
   (they cannot send anything out without it).
